# Evidence folders

Put each member's ORIGINAL paper hand-trace photo/scan (JPG/PNG) in their folder, then copy
`transcription_TEMPLATE.json` to `transcription.json` and fill in the values exactly as written on the paper.
The "Our working" tab then shows AGREES / DOES NOT AGREE against the baseline evidence run.

- dfs_kushal/          DFS connectivity check — Kushal (Data Lead)
- kruskal_shashaank/   Kruskal's table — Shashaank (Network Analyst)
- dijkstra_siddal/     Dijkstra table — Siddal (Routing Analyst)
- knapsack_joan/       knapsack grid — Joan (Investment Analyst)
- reference/           typed / computer-generated reference documents from the packs (NOT handwriting)

Never place generated, typed or simulated "handwriting" here.
